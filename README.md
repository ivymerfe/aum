# Aum

A simple utility that improves the macOS user experience.

## Features

- Better layout switcher: switch layouts with Caps Lock, on keydown and with no delay
- Better right click: always right-click on the trackpad when touching with two fingers
- Better screen rotation: rotate the cursor and scrolling along with the screen
- Fast navigation gesture: swipe up/down with three fingers → `Cmd+[` / `Cmd+]` (conflicts with Mission Control)
- Instant space switcher
- Middle click emulation
- Quick app switcher: switch to a recent app using the Option key

## Requirements

- macOS 27 (may work on 26 but it has not been tested)
